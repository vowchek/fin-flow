# Локальная разработка

## Требования

- JDK 21 (Temurin / Oracle / Liberica — без разницы)
- IntelliJ IDEA (Community достаточно: Maven, HTTP Client)
- Docker — только для этапа 1, не блокирует этап 0

Maven ставить не нужно: есть `./mvnw`.

## Импорт в IDEA

1. Open → корень репозитория.
2. Trust project, дождаться индексирования Maven.
3. Project SDK = 21.
4. Run `LedgerApiApplication` (профиль `local`).

Если IDEA предлагает «Load Maven project» — согласиться. Аннотации Lombok нет, плагин не нужен.

Данные H2: каталог `data/` в корне (в `.gitignore`).

## Миграции

Новый файл: `src/main/resources/db/migration/V2__....sql`.

Правила:

- только аддитивные изменения в уже выпущенных версиях (не редактировать `V1__init.sql` после того, как миграция хотя бы раз применилась у вас или в Docker);
- один V-файл = одно логическое изменение;
- проверять и на H2, и на Postgres, начиная с этапа 1.

## Стиль кода этапа 0

- records для DTO
- без Lombok
- без публичных JPA-сущностей в JSON
- исключения домена → 400, отсутствие → 404

## Тесты

`./mvnw test` поднимает in-memory H2 и гоняет сценарий «проект → время → деньги → сводка».

Новый endpoint без теста в том же духе не считается законченным.
