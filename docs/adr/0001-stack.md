# ADR 0001: стек этапа 0

## Статус

Принято.

## Контекст

Нужен проект учёта времени и денег, который открывается в IntelliJ IDEA, запускается локально и может вырасти до Docker + PostgreSQL + сервер. UI отложен. Язык backend задан: Java.

## Решение

- Spring Boot **3.5**, Java **21**, Maven Wrapper
- один модуль `ledger-api`
- REST `/api/v1`, OpenAPI
- JPA + Flyway
- H2 для `local` и тестов, PostgreSQL 16 для `docker`/`prod`
- порт **48121**, чтобы не драться с дефолтным 8080

## Почему не иначе

- **Quarkus / Micronaut** — меньше каноничных материалов и плагинов IDEA для первого проекта.
- **Spring Boot 4** — на момент старта Initializr отдавал 4.x, но экосистема (springdoc, примеры) для 3.5 стабильнее; переход на 4.x — отдельный ADR.
- **Gradle** — равноценен; Maven проще «Open pom.xml» и совпадает с большинством Java-канонов.
- **liquibase** — не хуже Flyway; Flyway выбран из‑за линейных версий файлами `V1`, `V2`.
- **отдельный frontend сейчас** — прямое нарушение запроса «для начала только бэк».
