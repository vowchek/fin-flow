# ADR 0002: одна БД, два профиля вместо «сразу Postgres»

## Статус

Принято.

## Контекст

Каноничный путь: как можно раньше тестировать на той БД, что будет в проде. При этом этап 0 должен работать в IDEA без Docker.

## Решение

- SQL миграций писать в подмножестве, общем для H2 PostgreSQL mode и Postgres
- тесты и `local` — H2
- Compose — настоящий Postgres
- на этапе 1 добавить Testcontainers, чтобы CI ловил расхождения

## Последствия

Иногда H2 пропустит конструкцию, которую отвергнет Postgres. Поэтому этап 1 (compose) обязателен до сервера, а не опционален.
