# Карта развития

Этапы последовательные. Следующий не начинаем, пока предыдущий можно каждый день запускать у себя.

## Этап 0 — сейчас: локальный API в IDEA

**Цель:** открыл проект в IDEA, нажал Run, есть живой HTTP API и тесты.

- Java 21, Spring Boot, Maven Wrapper
- H2 file, Flyway
- auth (JWT), фондовые/криптопортфели, месячные траты
- Swagger, `http/api.http`
- без UI, Docker не обязателен для локального запуска

**Критерий готовности:** `./mvnw test` зелёный; `GET /actuator/health` = UP.

## Этап 1 — тот же API в Docker с PostgreSQL

**Цель:** `docker compose up --build` поднимает то, что ближе к серверу.

- уже есть `Dockerfile` и `compose.yaml`
- прогнать миграции на Postgres 16, поправить SQL если H2 соврал
- добавить Testcontainers Postgres (тест «как в Docker») — следующий коммит этапа 1
- зафиксировать в README команды backup/restore volume

**Критерий:** compose здоров, данные переживают пересоздание контейнера `api` (volume БД цел).

## Этап 2 — контракт стабилизирован, подготовка к UI

**Цель:** API можно отдать фронтенду, не переписывая его каждую неделю.

- пагинация списков
- идемпотентность не обязательна, но явные коды ошибок и OpenAPI актуальны
- CORS для localhost UI
- auth: email/password + JWT уже есть (ADR 0003); на сервере обязателен свой `JWT_SECRET`

UI ещё может не существовать.

## Этап 3 — первый UI

**Цель:** один экран портфелей / трат за месяц — каркас UI уже в `web/` (auth, шапка, 3 раздела, диаграммы состава).

Стек UI не выбираем до этапа (по умолчанию: Vite + React, отдельная папка `web/`). Backend остаётся источником правды.

## Этап 4 — сервер

**Цель:** крутится на VPS, данные не на ноутбуке.

См. [DEPLOYMENT.md](DEPLOYMENT.md):

- один VM, Docker Compose
- Caddy или Nginx: HTTPS
- Postgres только во внутренней сети compose
- env-файл вне git
- `pg_dump` по cron

Не прыгаем в Kubernetes, пока нет второй машины и нулевого даунтайма как требования.

## Этап 5 — продукт, а не журнал

Включается **только** после ответов в OPEN-QUESTIONS, кандидаты:

- таймер start/stop
- ставка и «ожидаемый доход»
- несколько пользователей
- мультивалютность
- экспорт CSV / Telegram-бот

## Что не делаем «заодно»

- переписывание на микросервисы
- GraphQL до появления боли REST
- отдельная BFF-слойка
- шина событий
