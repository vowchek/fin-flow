# Предметная область (этап 0)

Ledger — журнал двух потоков: **затраченного времени** и **денежных движений**. Они встречаются в **проекте**, но не обязаны быть связаны формулой «часы × ставка».

## Допущения, пока нет ответов из OPEN-QUESTIONS

| Тема | Допущение |
| --- | --- |
| Пользователи | Один оператор. Авторизации нет. |
| Валюта | Одна, по умолчанию `RUB`. Поле `currency` уже есть, конвертации нет. |
| Время | Только закрытые интервалы. Таймера нет. |
| Деньги | Сумма всегда > 0, знак задаётся `direction`: `INCOME` или `EXPENSE`. |
| Проект | Необязателен: запись может быть «просто так». |
| Ставка | Не моделируется. |
| Клиенты | Отдельной сущности нет; имя клиента можно держать в названии проекта. |

Эти допущения можно ломать, но каждое ломание — отдельный этап, а не скрытое поле «на всякий случай».

## Сущности

```text
Project
  id, name, description, archived

TimeEntry
  id, project?, startedAt, endedAt, durationMinutes, note

MoneyEntry
  id, project?, direction, amount, currency, occurredOn, category, note
```

`durationMinutes` — производное поле (не вводится руками), чтобы сводки не пересчитывали интервалы каждый раз.

## Инварианты

- `endedAt >= startedAt`
- `amount > 0`
- `direction ∈ {INCOME, EXPENSE}`
- архивный проект не удаляется: на него могут ссылаться старые записи
- удаление time/money — физическое (этап 0). Мягкое удаление — отдельное решение, когда появится аудит

## Сводка

`GET /api/v1/summary` за период:

- число и сумма минут по `TimeEntry`
- сумма доходов, расходов и `net = income - expense` по `MoneyEntry`
- валюта сводки = `ledger.default-currency` (пока без разбиения по валютам)

## Что сознательно не входит в этап 0

- пользователи, сессии, ACL
- таймер
- счета, акты, НДС
- бюджеты и лимиты
- вложения (чеки)
- UI
